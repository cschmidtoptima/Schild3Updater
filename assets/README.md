# Grafikquellen

- OPTIMA-Logo: https://optima-computer.de/wp-content/uploads/2023/11/optima_logo_weiss_transparent.png
- Firmenwebseite: https://optima-computer.de/
- Eigenstaendiges Programm-Icon: `app-icon.svg`, ein Dokument mit der Ziffer 3 und Aktualisierungspfeilen. Es verwendet kein Firmensignet und wird beim Build in Aufloesungen von 16 bis 256 Pixeln gerendert.
- Bedienicons und Grundlage der Aktualisierungspfeile: https://github.com/lucide-icons/lucide (folder-open, save, copy, refresh-cw). Der mitgelieferte Lizenztext steht in `lucide-LICENSE` und ist auch im Programm unter **Info** abrufbar.

Alle Grafiken werden in die EXE eingebettet. Zur Anzeige ist kein Internetzugriff erforderlich.
